<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server DTO -> browser preview | server-returned block metadata becomes teacher-visible decision UI |
| browser block actions -> saved draft state | user actions can remove or replace one block while preserving the rest of the draft |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-8-03 | I | block preview UI | mitigate | Render block metadata from server DTO only and pin the required preview fields in source tests |
| T-8-04 | T | block remove/regenerate flow | mitigate | Scope actions by `blockKey` and preserve untouched blocks in local state and server responses |
| T-8-06 | T | course editor body | mitigate | Keep preview interactions separate from `mcontent` writeback and source-test the no-auto-apply contract |
</threat_model>
