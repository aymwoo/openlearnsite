<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| handler → publish BLL | Teacher-authenticated requests become privileged publish operations |
| publish DAL → SQL tables | One operation mutates `Courses`, `Mission`, `ListMenu`, and `CourseActivityPlanDraft` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | T | Publish DAL multi-table write | mitigate | Use one transaction for course, mission, menu, and draft-link writes so partial success cannot drift state |
| T-05-05 | E | Mission/menu route contract | mitigate | Force `Mupload=true` and `Ltype=1` in the publish core instead of trusting browser-submitted type values |
| T-05-06 | I | Student mission content | mitigate | Build `Mission.Mcontent` from the full server-validated draft so the student route never depends on client-side partial append state |
</threat_model>
