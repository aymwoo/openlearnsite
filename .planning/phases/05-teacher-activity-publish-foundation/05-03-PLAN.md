<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teacher browser → `teacher/aiprovider_api.ashx` | User-controlled publish settings and selected sections cross into privileged server code |
| handler → publish result → browser editor | Server response becomes the teacher-visible committed lesson body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | S | `activityPlanPublish` route | mitigate | Reuse `TryGetAuthorizedCourse(...)` before any publish work and reject invalid course ids early |
| T-05-08 | T | Browser publish toggle | mitigate | Treat `publishToStudents` as the only visibility input for the AI flow and do not read legacy mission defaults |
| T-05-09 | R | Editor write-back | mitigate | Replace editor content only with `updatedCourseContent` returned from the server-owned publish result |
</threat_model>
