<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI response JSON → browser renderer | Structured provider output crosses into the teacher UI and must not become executable HTML |
| preview state → lesson editor state | Generated draft data is visible beside the editor but must not mutate saved lesson content without teacher action |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | I | preview rendering path | mitigate | Render all server values through DOM element creation and `textContent` instead of `innerHTML` |
| T-02-07 | T | editor state during generation | mitigate | Keep `switchEditor` and `syncContent()` only for reading current content, not for applying generated draft output |
| T-02-08 | R | teacher review workflow | mitigate | Show preview-only metadata and avoid silent write-back so review remains explicit |
| T-02-09 | D | long-running browser request | accept | Show staged progress and timeout handling rather than adding client polling or retry loops in this phase |
</threat_model>
