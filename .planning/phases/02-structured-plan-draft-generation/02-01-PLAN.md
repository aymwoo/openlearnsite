## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `teacher/aiprovider_api.ashx` | Teacher-entered topic, goals, duration, and existing lesson content enter the server as untrusted request data |
| `AIActivityPlanDraftGenerator` → AI provider | Structured planning context and current lesson content leave the app and are sent to the configured provider |
| AI provider → `AIActivityPlanDraftHelper` | Untrusted model output must be normalized and validated before the browser can see it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T | `activityPlan` request shaping | mitigate | Bound all request fields and reject empty topics before generation starts |
| T-02-02 | I | provider prompt and response path | mitigate | Keep existing course content as support context only, and return structured draft data instead of raw provider output |
| T-02-03 | T | model output normalization | mitigate | Permit only safe normalization and reject any response that still lacks required sections or step fields |
| T-02-04 | D | provider call and parsing loop | mitigate | Reuse existing request timeout behavior and fail once parsing/validation cannot recover a complete draft |
| T-02-05 | E | skill/runtime prompt control | accept | Admin-editable scoped skill text is allowed, but hardcoded schema guardrails in prompt builder and parser keep the runtime contract fixed |
</threat_model>
