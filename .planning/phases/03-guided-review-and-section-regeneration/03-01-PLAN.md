## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `teacher/aiprovider_api.ashx` | The client sends untrusted `sectionTarget` and current draft JSON that must not be trusted directly |
| AI provider → `AIActivityPlanDraftHelper` | Untrusted model output must be constrained to one allowed section and revalidated before merge |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | T | section target input | mitigate | Validate `sectionTarget` against the fixed five-key allowlist before any provider call or merge |
| T-03-02 | T | current draft payload | mitigate | Parse the current draft through shared helper validation instead of trusting raw browser JSON |
| T-03-03 | T | section-regeneration response | mitigate | Reject responses that return the wrong key, extra untargeted data, or incomplete section content |
| T-03-04 | D | merge path | mitigate | Return `success:false` when parsing or validation fails so invalid retries never replace the current draft |
</threat_model>
